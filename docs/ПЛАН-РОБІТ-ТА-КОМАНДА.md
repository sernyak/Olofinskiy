# План робіт, розподіл ролей і мінімальна команда
## Проєкт «Просування Миколи Олофінського»

> **Для кого цей документ:** для Миколи — щоб побачити повний обсяг робіт, зрозуміти, хто що має робити, і чому одна людина це не витягне. Для Олександра — як інструмент переговорів і основа для формування команди.

---

## 0. Проблема, яку ми вирішуємо

Зараз у Миколи в команді одна людина — **асистентка**. На неї покладено:

- Побутові доручення (дім, посилки, авто на СТО)
- Організація «Чоловічого кола» і залучення учасників
- Ведення соцмереж (контент-план, тексти, публікація)
- Зйомка та монтаж відео
- Дизайн банерів для заходів
- Запуск реклами в Meta
- Генерація ідей для нових форматів
- «Пушити» Миколу, щоб проєкти рухались

**Результат:** асистентка вигорає → Микола незадоволений → на «Чоловіче коло» приходять 5–6 людей → клієнтська база не росте → нічого не рухається.

**Причина:** це не проблема конкретної людини — це проблема **структури**. Один штат не може робити роботу восьми ролей.

## 1. Що таке «особистий асистент» у класичному розумінні

Перш ніж говорити про маркетинг, зафіксуємо: **що входить в обов'язки асистента, а що — ні**.

### ✅ Що ВХОДИТЬ у роль PA (Personal Assistant)

| Функція | Приклади |
|---|---|
| **Календар і розклад** | Планування зустрічей, нарад, сесій; контроль дедлайнів; нагадування |
| **Комунікація** | Перший контакт по дзвінках/месенджерах; фільтрація вхідних повідомлень; листування від імені Миколи |
| **Логістика** | Бронювання, відрядження, квитки, оренда приміщень |
| **Адміністрування** | Документи, договори, рахунки, контроль оплат |
| **Побутові доручення** | Посилки, авто на СТО, особисті покупки, домашні питання |
| **Координація команди** | Передача доручень підрядникам, контроль виконання |
| **Організація заходів** | Букінг локації, список учасників, реєстрація, логістика Чоловічого кола |

### ❌ Що НЕ ВХОДИТЬ у роль PA

| Функція | Чому це окрема роль |
|---|---|
| Розробка маркетингової стратегії | Потрібні знання ринку, аналітика, позиціонування |
| Написання контент-плану та текстів | Потрібні копірайтинг, розуміння ЦА, tone of voice |
| Зйомка відео | Потрібні обладнання, навички операторської роботи |
| Монтаж відео, Reels, Stories | Потрібні спецсофт (Premiere/CapCut), навички монтажу |
| Дизайн банерів, візуалу | Потрібні Figma/Canva на рівні вище базового |
| Налаштування та ведення таргетованої реклами | Потрібні знання Meta Ads Manager, аналітика, A/B тести |
| Генерація ідей для контенту та форматів | Потрібні дослідження трендів, конкурентний аналіз |
| Стратегічне планування проєктів | Потрібні PM-навички, бачення воронки |

> **Висновок:** Якщо «просунути проєкт» = «написати + знайти + зняти + змонтувати + запустити рекламу + аналізувати + планувати», то це **мінімум 4–5 різних спеціалізацій**, а не розширений функціонал асистента.

## 4. Оптимізація: від 9 ролей до мінімальної команди

### Принцип суміщення

Ролі об'єднуються, якщо:
- (а) навички перетинаються,
- (б) сумарне навантаження не перевищує ~35–40 годин/тиждень,
- (в) немає конфлікту пріоритетів.

## 5. Порівняння: що є зараз vs що потрібно

| Функція | Зараз (хто робить) | Має робити (роль) |
|---|---|---|
| Стратегія, позиціонування, офери | ❌ Ніхто | Маркетолог |
| Контент-план, контент-матриця | Асистентка (⚠️) | SMM + Маркетолог |
| Тексти постів | Асистентка (⚠️) | Копірайтер / SMM |
| Зйомка відео | Асистентка (⚠️) | Відеограф |
| Монтаж Reels/YouTube | Асистентка (⚠️) | Монтажер |
| Дизайн банерів | Асистентка (⚠️) | Дизайнер |
| Таргет (Meta Ads) | Асистентка (⚠️) | Таргетолог |
| Модерація соцмереж | Асистентка (⚠️) | SMM |
| Генерація ідей, нові формати | Асистентка (⚠️) | Маркетолог + SMM |
| «Пушити Миколу» | Асистентка (⚠️) | Проєкт-менеджер |

**З 14 функцій, які зараз виконує асистентка, лише 4 реально входять у її роль.** Решта 10 — це робота маркетолога, SMM, відеографа, дизайнера та таргетолога.

## 6. Що дає правильна структура

### Без структури (зараз)

- 1 людина → 14 функцій → якість кожної ≈ 15% від потрібної
- Вигорання асистентки
- Незадоволення Миколи
- «Чоловіче коло»: 5–6 людей, без системи залучення
- Консультації: потік не росте
- Дохід: стагнація

### З мінімальною командою (4 людини)

- Кожна функція закрита компетентною людиною
- Системна воронка: контент → прогрів → заявка → консультація → пакет
- Зростання «Чоловічого кола» до 15–25 учасників
- Конверсія учасників Кола в клієнтів консультацій
- Зростання доходу в **3–4 рази** (за рахунок оптимізації воронки, без додаткового трафіку — розрахунок з [Етапу 9](file:///Users/oleksandrserniak/Documents/Psy_mrktng/10_%D0%95%D1%82%D0%B0%D0%BF9-10_%D0%9F%D1%80%D0%BE%D0%B4%D0%B0%D0%B6%D1%96_LTV_%D1%96_%D0%BC%D0%B0%D1%81%D1%88%D1%82%D0%B0%D0%B1%D1%83%D0%B2%D0%B0%D0%BD%D0%BD%D1%8F.md))
- Асистентка працює у своїй зоні, не вигорає

## 7. Варіанти впровадження (поступово)

### Крок 1 (зараз): + Маркетолог-стратег

> **Це ви, Олександре.** Стратегія, воронка, позиціонування, координація. Найважливіший найм, без якого решта не має сенсу.

### Крок 2 (через 2–4 тижні): + Відеограф-монтажер

> Батч-зйомка + монтаж. Проєктна оплата, не штат. Фрілансер може коштувати 8–15 тис. грн/міс за 2 зйомки + монтаж 8–16 одиниць контенту.

### Крок 3 (через 1–2 місяці): + SMM / копірайтер

> Повна зайнятість або парт-тайм. Публікація, модерація, тексти. 10–20 тис. грн/міс.

### Крок 4 (коли воронка працює): Таргет

> Можна почати самостійно або найняти підрядника на проєктній основі. 5–15 тис. грн/міс + рекламний бюджет.

## 8. Що сказати Миколі

> **«Миколо, ваша асистентка робить свою роботу добре — адміністрування, логістику, комунікацію. Проблема не в ній. Проблема в тому, що крім своєї роботи їй доручено ще 10 функцій, які потребують зовсім інших компетенцій — стратегія, копірайтинг, відеопродакшн, таргет, дизайн. Це як попросити хірурга ще й вести бухгалтерію. Він може спробувати, але результат не буде хорошим, і він вигорить.**
>
> **Ось повний перелік з 60+ задач, які потрібні для роботи воронки. Ось хто повинен їх робити. Мінімальна команда — 4 людини. І це реально окупається: якщо просто правильно обробляти ті заявки, що вже є, дохід може зрости в 3–4 рази навіть без реклами.»**
